# Documentation overview

1. `README.md` — quick entry point
2. `docs/INSTALL.md` — first-time setup checklist
3. `docs/STARTUP.md` — how to start the stack
4. `docs/FAQ.md` — common issues and answers
5. `docs/DEPLOY.md` — migration and deployment notes
6. `docs/FINAL-DEPLOY.md` — shortest deployment order

- Port choices are stored in `.runtime/` after startup.
